Play Console 의 메뉴 이름은 바뀔 수 있으니, 화면이 다르면 비슷한 이름을 찾으세요.

## 2. 등록 순서

### ① Play Console 본인 인증
- https://play.google.com/console 에서 개발자 본인 인증(주소 등)을 마칩니다.
- 메일 속 링크 대신 위 주소에 직접 들어가서 진행하세요.
- 개인 계정으로 유료 결제를 붙이면 주소가 스토어에 공개될 수 있습니다. 입력 전에 안내를 꼭 읽어 보세요.

### ② 안드로이드 앱 파일 만들기 (PWABuilder)
1. https://www.pwabuilder.com 에 `https://catholicgram-dey7.vercel.app` 을 넣고 **Start** 를 누릅니다.
2. **Package For Stores → Android → Generate Package** 를 누릅니다.
3. 옵션
   - Package ID: `com.catholicgram.app`
   - App name: `가톨릭그램`
   - Signing key: **Create new** (새로 만들기)
4. 내려받은 zip 안의 **서명 키 파일(.keystore)과 비밀번호(signing-key-info.txt)** 는 USB 등 안전한 곳에 따로 보관합니다.
   - 잃어버리면 앱 업데이트가 어려워집니다.
   - 채팅이나 메일로 보내지 마세요.

### ③ Play Console 에 앱 만들기
1. **앱 만들기**를 누릅니다.
   - 앱 이름: 가톨릭그램
   - 기본 언어: 한국어
   - 유형: 앱
   - 가격: 무료
2. **테스트 → 비공개 테스트**에서 트랙을 만들고 zip 안의 `.aab` 파일을 올립니다.

### ④ 앱과 웹사이트 연결 (주소창 없이 전체 화면으로 열리게)
1. Play Console **설정 → 앱 무결성(App signing)** 에서 **앱 서명 키 인증서의 SHA-256 지문**을 복사합니다.
2. Vercel 환경 변수에 넣습니다.
   - `ANDROID_PACKAGE_NAME` = `com.catholicgram.app`
   - `ANDROID_SHA256_FINGERPRINTS` = 위 지문 (PWABuilder zip 의 `assetlinks.json` 에 있는 지문도 있으면 쉼표로 함께)
3. Redeploy 한 뒤 assetlinks.json 주소를 열어 지문이 보이는지 확인합니다.

### ⑤ 비공개 테스트 (개인 계정은 필수)
- 2023년 11월 이후에 만든 개인 개발자 계정은, **테스터 12명 이상이 14일 동안 계속 참여**해야 정식 출시(프로덕션)를 신청할 수 있습니다.
- **안드로이드 휴대폰을 쓰는 교우 12명 이상을 미리 모아 두세요.** 테스터의 구글 계정(Gmail) 주소가 필요합니다.

### ⑥ 스토어 등록정보와 앱 콘텐츠 설문
아래 3·4번의 글과 답을 옮겨 적습니다.

## 3. 스토어 등록정보 (복사해서 사용, 2026-10-30 지금 기능으로 고침)

Play Console → **성장 → 스토어 등록정보 → 기본 스토어 등록정보** 에서 바꾸고 저장한 뒤, **게시 개요 → 검토를 위해 변경사항 전송**. 앱 파일을 새로 만들 필요는 없습니다.
스크린샷 속 사람·글·사진은 모두 예시로 만든 것입니다(다시 만들기: scratchpad 의 `store.mjs` → `storecompose.mjs`).

**앱 이름 (30자 이내, 바꾸고 싶을 때만)**
```
가톨릭그램 - 가톨릭 교우 공간
```

**간단한 설명 (80자 이내)**
```
기도와 일상을 나누는 가톨릭 교우 공간. 사진·메시지·사랑방·익명 고민 상담까지
```

**자세한 설명 (4000자 이내)** — 메타데이터 정책상 이모티콘은 넣지 않음
```
가톨릭그램은 가톨릭 교우들이 기도와 일상, 신앙의 기쁨과 고민을 함께 나누는 공간입니다.
큰 글씨와 넉넉한 단추로 어르신도 쉽게 쓰실 수 있도록 만들었습니다.

■ 함께 기도해요
• 오늘의 기도 지향을 올리고 교우들과 함께 기도합니다.
• 게시글마다 '기도'와 '공감'으로 마음을 보탭니다.
• 축일과 생일을 맞은 교우를 알려 드리고, 함께 축하 인사를 나눕니다.

■ 사진·영상 나눔
• 미사, 성지순례, 봉사 활동의 사진(한 번에 10장까지)과 짧은 영상을 나눕니다.
• 사진 효과: 자르기, 이모티콘 붙이기, 얼굴 모자이크를 한 화면에서 할 수 있습니다.
• 가톨릭그램 음악이나 유튜브 뮤직의 노래를 글에 넣을 수 있습니다.
• 24시간 동안 보이는 스토리로 오늘의 순간을 나눕니다.

■ 교우와 대화
• 1:1 메시지와 단체 채팅방에서 사진·동영상·이모티콘을 주고받습니다.
• 답장, 감정 표시, 대화 내용 찾기, 날짜별 구분으로 대화를 쉽게 볼 수 있습니다.
• 모든 교우가 함께하는 '사랑방'에서 실시간으로 인사를 나눕니다.
• 가톨릭그램만의 귀여운 이모티콘(아멘이·몽글이·딩동이·루)을 쓸 수 있습니다.

■ 마음 나눔
• 익명 고민 상담: 이름을 밝히지 않고 신앙과 삶의 고민을 나누고, 따뜻한 답글과 기도로 위로를 받습니다.
• 사연함: 운영자에게 사연을 보내고 답장을 받을 수 있습니다.

■ 내 공간
• 프로필 사진과 소개, 내가 올린 글과 영상을 한곳에 모아 봅니다.
• 축일과 생일을 등록하면 그날 프로필에 축하 표시가 나타납니다.

■ 알림
• 댓글, 답글, 메시지, 팔로우, 축일·생일 소식을 휴대폰 알림으로 받습니다.
• 알림 소리를 여러 가지 중에서 고를 수 있습니다.

■ 보기 편하게
• 글씨 크기(보통·크게·아주 크게)와 다섯 가지 화면 색을 고를 수 있습니다.
• 휴대폰이 다크 모드면 어두운 화면으로 맞춰 줍니다.

■ 안전한 공동체
• 부적절한 글과 사용자는 신고·차단할 수 있으며, 운영자가 확인합니다.
• 회원 탈퇴와 개인정보 삭제는 앱 안에서 직접 할 수 있습니다.
```

**앱 카테고리**: 소셜 (또는 라이프스타일)
**연락처 이메일**: (운영자 이메일)

## 4. 앱 콘텐츠 설문 예상 답안

질문 문구는 화면에 따라 다를 수 있습니다. 내용이 맞는지 확인하며 답하세요.

- **개인정보처리방침**: 위 privacy URL
- **광고 포함 여부**: 후원 배너(업체 광고)를 실제로 띄우고 있으면 **예**, 아니면 아니요
- **앱 액세스 권한**: 일부 기능은 로그인 필요
  - 심사자용 로그인 방법을 적어야 합니다.
  - 카카오·구글·네이버 로그인만 있으므로, 심사용 구글 계정을 하나 만들어 아이디·비밀번호를 적어 주세요.
- **타겟층**: 18세 이상 (어린이 대상 아님)
- **콘텐츠 등급 설문**
  - 사용자끼리 소통·콘텐츠 공유: 예
  - 폭력·성적 내용·도박·약물: 없음
  - 위치 공유: 아니요
  - 디지털 상품 구매: 아니요
- **뉴스 앱 / 정부 앱 / 금융·건강 기능**: 아니요
- **데이터 보안 (Data safety)**
  - 수집하는 데이터
    - 이름(세례명·닉네임)
    - 이메일 주소
    - 사용자 ID
    - 사진·동영상
    - 앱 내 메시지
    - 기타 사용자 생성 콘텐츠(게시물·댓글)
    - 앱 활동(접속 기록)
  - 목적: 앱 기능, 계정 관리
  - 제3자 공유: 아니요 (서비스 제공업체 처리는 공유가 아님)
  - 전송 중 암호화: 예
  - 데이터 삭제 요청: 예 (account-deletion URL)
