# 움직이는 이모티콘 만들기 (시안)

운영자가 AI 로 만든 GIF(신부님 캐릭터 9장면)를 받아, 그림은 그대로 두고 효과·글자·움직임만 더해
움직이는 WebP 이모티콘을 만드는 스크립트. 2026-11-07 운영자에게 샘플 10개를 보여 준 단계 — 아직 앱에 넣지 않음.

- `make.py`: `/tmp/cggif/f0~8.png`(GIF 프레임)와 `EB.ttf`(NanumSquareRoundEB woff2 → ttf) 를 읽어 `/tmp/cggif/out/*.webp`(투명 바탕, 12프레임 0.1초) + 미리 보기 GIF 를 만든다
  - 바탕(크림색)은 가장자리에서 이어진 곳만 투명으로, 윙크 장면의 박힌 글자는 OpenCV inpaint 로 지우고 로만 칼라는 다른 장면에서 붙임
  - 얼굴을 새로 그리지는 못하므로 GIF 안의 표정(미소·웃음·주먹·윙크)만 쓴다. 새 표정은 운영자가 같은 도구로 낱장을 더 만들어 주어야 함
- 앱에 넣을 때: 256px 로 줄여 `public/stickers/<팩>/NN.webp`(움직이는 WebP 그대로 `<img>` 로 보임), `lib/stickers.ts` 에 팩·말 추가
